**NativeTavern v0.1.17 (Build 41)**

**Connections and parameters**
• Connection profiles no longer lose your API key: applying a profile saved without a key keeps the key you already use, and a key missing from the active configuration is restored on launch.
• Every sampling parameter can now be left out of a request. Uncheck it in Advanced sampler settings and it is omitted for every provider — this fixes endpoints such as xAI/Grok that reject presence_penalty.
• Fixed duplicate Moments posts and made the selected API key survive provider switches and restarts.

**Cards and diagnostics**
• Fixed imports of community character cards whose numeric fields are stored as strings, and fixed an author-note editor overflow on iOS.
• The capability check now reports MCP servers from their real state instead of always showing "not available in this build".

**Availability**
• iOS: 1.2.14 (Build 41) submitted to App Store review.
• Android: version 41 submitted to Google Play production.
